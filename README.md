# Responsive Web Design Website

My personal responsive website, built for the Limelight internship task by customising the
[Responsive-web-design-Website](https://github.com/Lime-Light-TechLead/Responsive-web-design-Website) Bootstrap project.

## Sections

1. **About**: who I am and my tech stack
2. **Projects & experience**: past coding activity and work
3. **Academics**: my university story
4. **Favourites**: activities, food, sport and music
5. **Contact**: where to find me

## Built with

- HTML and CSS
- Bootstrap 5 (grid and responsive navbar)
- Deployed with GitHub Pages
